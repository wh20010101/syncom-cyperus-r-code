# Input data

This directory is intentionally empty in the public repository.

Place the following processed input files here before running the scripts:

- `microbial_OTU_table.xls` — tab-separated OTU/genus table; columns are samples (`W*_*`).
- `factorial_traits.xlsx` — Sheet1, 42 rows x 39 columns, `Sample` + 38 traits.

Other module-specific inputs are described in the main `README.md`.

Raw sequencing and metabolomics data are available from the repositories listed in the main `README.md`.
